# GUI folder

| Folder   | What goes in it                              |
| -------- | -------------------------------------------- |
| hud/     | Always-visible info (resources, time, speed) |
| panels/  | Windows for selected colonists / buildings   |
| menus/   | Main menu, pause menu, settings              |
| build/   | The build menu                               |
| widgets/ | Reusable pieces (buttons, tooltips)          |
| styles/  | CSS files                                    |
| gui.ts   | Starts the GUI and connects the pieces       |
